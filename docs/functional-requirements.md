# Functional Requirements

## TODO List Application

This document outlines the functional requirements for the TODO list application.

### Core Features

#### 1. Task Creation
- User can create tasks with a due date

#### 2. Task Completion
- User can mark tasks as finished

#### 3. Task Management
- User can edit tasks

#### 4. Sub-tasks
- User can add sub tasks to tasks with due dates that are less than the parent task date

#### 5. Task Sorting
- User can sort tasks by due date
