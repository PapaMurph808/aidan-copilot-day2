# UI Guidelines

## Design System

This document outlines the user interface guidelines for the TODO list application.

### Color Palette

The application should use a pastel color palette with an emphasis on purple and lavender shades:

- **Primary Colors**: Soft purples and lavenders
- **Accent Colors**: Complementary pastel tones
- **Background**: Light, airy tones that complement the pastel palette
- **Text**: Ensure proper contrast for readability while maintaining the soft aesthetic

### Interactive Elements

#### Button Feedback
- All button clicks must provide solid visual feedback
- Consider effects such as:
  - Scale transformations
  - Color changes
  - Ripple effects
  - Shadow changes
- Feedback should be immediate and noticeable

#### Deletion Animation
- When items (tasks or subtasks) are deleted, they should "poof" away
- Implement a smooth, playful animation that makes the deletion feel delightful
- Consider effects such as:
  - Fade out with scale transform
  - Particle effects
  - Slide and fade animations
  - Bounce or elastic easing

### Visual Consistency

- Maintain consistent spacing and padding throughout the application
- Use smooth transitions for state changes
- Ensure all interactive elements have hover and active states
- Keep the interface clean and uncluttered
